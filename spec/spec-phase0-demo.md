# Phase0 项目规格书 - 最小可用多Agent旅行助手Demo

## 1. 阶段目标

完成**纯本地、内存运行、Mock 数据**的多智能体调度 Demo。
核心目标：跑通「主控拆解任务 - 分发子Agent - 子Agent独立返回结果 - 主控汇总输出」的完整链路。

本阶段定位：**验证架构可行性，不做商用、不做完整功能、不做对外服务**。

## 3. 架构与角色（严格锁死，不许改动）

### 总架构

单主控 Agent 统筹，4个专业子 Agent 分工执行，无跨角色乱调度。

### 固定5个智能体

1. Travel Supervisor 旅行主控Agent
   - 负责：接收用户旅行需求、拆解任务、合理分发到对应子Agent、汇总所有结果生成最终方案
2. FlightSearchAgent 机票Agent
   - 负责：输出模拟机票方案、价格、时段信息
3. HotelBookingAgent 酒店Agent
   - 负责：输出模拟酒店方案、房型、价格、位置信息
4. ActivitiesAgent 游玩活动Agent
   - 负责：输出目的地每日游玩行程、特色活动推荐
5. BudgetingAgent 预算Agent
   - 负责：汇总机票+酒店+活动费用，生成总预算、费用明细

## 4. 本阶段必须实现的功能（仅这些）

1. 命令行接收用户输入：目的地、出行天数、出行时间
2. 主控Agent完成任务拆解与分发
3. 四个子Agent独立产出标准化Mock数据结果
4. 主控汇总所有数据，输出一份结构清晰、完整的旅行规划方案文本
5. 保证项目可正常启动、无报错、链路完整可跑通
